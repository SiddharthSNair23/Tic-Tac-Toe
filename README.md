# Tic Tac Toe

A classic Tic Tac Toe game built in Unity with C#.

## Features
- 1-player mode against an AI opponent
- 2-player local mode
- Win, lose, and draw detection with a game over screen
- Restart button

## How to play
Click a square to place your mark. Get three in a row to win.

## Built with
- Unity
- C#

## Run it from source
1. Clone this repo.
2. Open the folder in Unity Hub.
3. Open `Assets/Scenes/TicTacToe.unity` and press Play.
